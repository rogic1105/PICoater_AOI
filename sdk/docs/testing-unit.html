Unit Test
純邏輯，無 IO、無 await time-based、無 UI

1. 目的

驗證「純函式級」邏輯的正確性。無 IO、無 time-based、無 UI。所有對外依賴用 Moq 注入。

2. csproj 模板（.NET Framework 4.8 + NUnit 3）

<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net48</TargetFramework>
    <LangVersion>7.3</LangVersion>
    <Platforms>x64</Platforms>
    <OutputType>Library</OutputType>
    <IsPackable>false</IsPackable>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="NUnit"             Version="3.14.0" />
    <PackageReference Include="NUnit3TestAdapter" Version="4.5.0" />
    <PackageReference Include="Microsoft.NET.Test.Sdk" Version="17.8.0" />
    <PackageReference Include="Moq"               Version="4.20.70" />
  </ItemGroup>
  <ItemGroup>
    <ProjectReference Include="..\..\..\src\dotnet\YourApp\YourApp.csproj" />
  </ItemGroup>
</Project>

3. InternalsVisibleTo（讓 test 看到 internal 方法）

主專案的 Properties\AssemblyInfo.cs 加：

[assembly: InternalsVisibleTo("YourApp.Tests")]
[assembly: InternalsVisibleTo("YourApp.Integration.Tests")]
[assembly: InternalsVisibleTo("YourApp.Stress.Tests")]
[assembly: InternalsVisibleTo("DynamicProxyGenAssembly2")]  // Moq 需要
反模式：把 internal 改成 public「只為了讓 test 看到」。改用 InternalsVisibleTo，保持封裝。

4. 範例：FSM 邏輯 + Mock 注入

[Test]
public async Task FSM_GoesToIdle_OnConnect()
{
    var mockClient = new Mock<IModbusTcpClient>();
    mockClient.Setup(c => c.ConnectAsync(It.IsAny<string>(), It.IsAny<int>(), It.IsAny<int>()))
              .ReturnsAsync(true);
    mockClient.Setup(c => c.IsConnected).Returns(true);

    var ctrl = new IoGrabController(mockClient.Object) { AutoBackgroundLoop = false };
    await ctrl.StartAsync("192.168.1.1");

    Assert.That(ctrl.State, Is.EqualTo(IoState.Idle));
    mockClient.Verify(c => c.ConnectAsync("192.168.1.1", It.IsAny<int>(), It.IsAny<int>()), Times.Once);
}
背景 loop / Timer：如果 SUT 內部有背景 loop（如 BackgroundLoop / Tick timer），test 內必須關掉 （如本例 AutoBackgroundLoop = false），避免跟手動觸發的 method 並發 race 造成 flaky test。

5. 分類判斷

  • 用 Mock<I*> 注入 + 純函式驗證 → Unit ✓
  • 用 Path.GetTempFileName() / File.WriteAllText → 改成 Integration
  • for (i = 0; i < 1_000_000; i++) / Task.Delay(minutes) → 改成 Stress
