# project-context

Read [`references/repository-reference.md`](references/repository-reference.md) only for the sections
needed by the current task. Treat root and nested `AGENTS.md` files as authoritative rules; this
reference supplies detailed maps and lookup tables.

Before editing:

1. Locate the feature, control, setting, or service in the reference.
2. Confirm the entry against current code with `rg`; the reference can become stale.
3. Read the closest nested `AGENTS.md` and the task-specific skill.
4. Update the reference when a file owner, control name, setting, or repository location changes.
