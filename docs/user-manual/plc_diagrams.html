2. SFC — Sequential Function Chart 順序功能圖 (IEC 61131-3)

S0 — Disconnected 未連線
N: StartAsync(ip, port) 嘗試連線
N: ReconnectTimer ← 5s interval 背景重連
T0: ConnectAsync() == OK 連線成功
S1 — Idle 待機
N: DO PC_ALIVE ← HIGH   PC 存活信號
N: DO MURA ← LOW     清除瑕疵信號
N: DO PC_BUSY ← LOW    清除忙碌信號
N: _lastDiStart ← false    重置邊緣偵測
N: PollTimer.Start(500ms)   開始輪詢
T1: DI_START ↑ rising edge 上升緣 AND State == Idle
S2 — Running 取像中
P1: OnStartRequested → 觸發 Grab 開始
N: DO PC_BUSY ← HIGH   忙碌信號
T2a: meanPeak > ErrMean 均值超標
OR maxPeak > ErrMax 峰值超標
S3 — MURA 瑕疵
P1: DO MURA ← HIGH   瑕疵信號
N: 保持 PC_BUSY = HIGH Keep BUSY
T3: DI_START ↓ falling edge 下降緣
T2b: DI_START ↓ falling edge 下降緣
(無瑕疵 no MURA)
S4 — Stopping 停止中
P1: OnStopRequested → 觸發 Grab 停止
N: ClearMura → DO MURA ← LOW 清除瑕疵
N: DO PC_BUSY ← LOW     清除忙碌
T4: Cleanup complete 清除完成
↑ 回到 S1 Idle 待機 / Return to S1
S5 — Faulted PLC 故障
P1: DO MURA ← LOW    清除瑕疵 Clear MURA
P1: DO PC_BUSY ← LOW   清除忙碌 Clear BUSY
P1: OnStopRequested    緊急停止 Emergency stop
N: 保持 PC_ALIVE = HIGH   Keep PC alive
N: 持續 Polling      Continue polling
T5: DI_PLC_ALIVE restored 心跳恢復
→ 回到 S1 Idle / Return to S1
S6 — CommLost 通訊中斷
P1: _plc.Dispose()     釋放 TCP Release TCP
P1: OnConnectionChanged(false) 通知 UI
P1: OnStopRequested     緊急停止 Emergency stop
N: ReconnectTimer ← 5s   背景重連 Auto reconnect
T6: ReconnectAsync OK 重連成功
→ 回到 S1 Idle / Return to S1
SFC 動作限定符 Action Qualifiers — N: 非儲存 Non-stored (持續執行 continuous)  P1: 上升脈衝 Pulse rising (進入時執行一次 execute once on entry)
