雙擊【監控主畫面】
ResetMainDisplayView
自動填滿
單台：cam.ResetSecondaryDisplayView（M_SCALE_DISPLAY = M_ONCE + M_CENTER_DISPLAY）
全域合圖：_mergedDisplay（M_SCALE_DISPLAY = M_ONCE + M_CENTER_DISPLAY）
三擊【監控主畫面】
SetPhysicalMagnification1x
實體倍率 1:1（螢幕 1cm = 實際 1cm）
zoom = opsInMm / screenMmPerPx，以面板中心為基準計算 pan 偏移
單台：opsInMm = 選中相機的 OPS / 1000
全域合圖：opsInMm = _mergedRefOpsMm（第一台相機 OPS / 1000）
滾輪【監控主畫面】
WheelZoomFilter → ApplyCustomZoom
1.1x 步進縮放（以面板中心為基準）
factor = 1.1（上滾放大）/ 1/1.1（下滾縮小），zoom 範圍 0.05~32.0
pan 基準：imgX = panX + panelW/2 / oldZoom → newPanX = imgX - panelW/2 / newZoom
單台：cam.SetSecondaryDisplayZoom（M_UPDATE DISABLE → MdispZoom + MdispPan → M_UPDATE ENABLE）
全域合圖：直接操作 _mergedDisplay（MdispZoom + MdispPan，同上 DISABLE/ENABLE 防閃爍）
滑鼠移動【監控主畫面】
HandleMouseDataChanged / MergedMouseStatusHandler
座標狀態列：位置(mm) + 座標(px) + 亮度 + X/Y 範圍 + 實體倍率
單台：physicalX = startPosMm + x × opsInMm，physicalY = y × rowPitchMm
全域合圖：physicalX = _mergedMinStartMm + x × _mergedRefOpsMm，physicalY = y × rowPitchMm
視野範圍：viewLeftMm = startMm + panOffX × opsMm，viewRightMm = startMm + (panOffX + panelW / zoom) × opsMm
實體倍率 = zoom × screenMmPerPx / opsInMm
即時全域合圖（系統流程）EnableGlobalMerge / DisableGlobalMerge
引用：開始抓取 · 監控縮圖點擊 · 檢測設定變更
合圖方式 = 全域時觸發。觸發時機：① StitchMode 變更（_propertyGrid_PropertyValueChanged）② 首次開始抓取（btnCameraGrab_Click 分配相機後）。使用 MIL MbufChild2d + MbufCopyClip 在 GPU 端完成跨相機合圖，不經 CPU。
EnableGlobalMerge(opsUm[], startPosMm[])
refOpsMm = opsUm[0] / 1000（參考像素尺寸，取第一台相機）
遍歷所有相機：widthMm = FrameWidth × ops / 1000 → 計算 minStart / maxEnd / maxH
totalW = ceil((maxEnd - minStart) / refOpsMm)，maxH = 最高相機高度
各相機 xOffset = round((pos - minStart) / refOpsMm)，按 xOffset 排序
Overlap 分割：相鄰相機 overlap = rightEdge - leftEdge（前相機右邊 - 後相機左邊）
overlap > 0 → mid = leftEdge + overlap / 2（整數截斷）；前相機 drawRight = mid，後相機 drawLeft = mid
每台相機存 _mergedSrcClipLeft / _mergedSrcClipWidth（來源裁切區域）
MbufAlloc2d(sysId=System0, totalW, maxH, 8+M_UNSIGNED, M_IMAGE+M_DISP+M_PROC) → _mergedBuffer
MbufClear(_mergedBuffer, 0)（黑底）
儲存座標系：_mergedMinStartMm / _mergedRefOpsMm / _mergedTotalW
解除所有相機 secondary display（SetSecondaryDisplay(IntPtr.Zero)）
MdispAlloc → MdispSelectWindow(_mergedDisplay, _mergedBuffer, mainPanel.Handle)
MdispControl：M_SCALE_DISPLAY=M_ONCE + M_CENTER_DISPLAY + M_MOUSE_USE
MdispHookFunction(_mergedDisplay, M_MOUSE_MOVE, MergedMouseStatusHandler) → 座標狀態列
每幀 ProcessingFunction callback（每台相機獨立觸發）
GPU 處理 → MbufCopy 到 _milDisplayBuffer（正常流程）
_mergedTargetBuffer ≠ M_NULL →
MbufChild2d(_milDisplayBuffer, clipLeft, 0, clipWidth, frameHeight) → childBuf（裁切子 buffer）
dstX = _mergedTargetOffsetX + clipLeft
MbufCopyClip(childBuf, _mergedBuffer, dstX, 0)（GPU→GPU，跨 System 由 MIL DMA 路由）
MbufFree(childBuf)（每幀建立/釋放，MIL 內部快取）
監控主畫面：7 台即時合圖（重疊區域中點分界，前相機取左、後相機取右）
LiveOverviewTimer_Tick → UpdateOverviewChart(LiveViewRangeProvider)
LiveViewRangeProvider：IsGlobalMergeActive → TryGetMergedViewRange
viewLeftMm = _mergedMinStartMm + panOffX × _mergedRefOpsMm
viewRightMm = _mergedMinStartMm + (panOffX + panelW / zoomX) × _mergedRefOpsMm
監控全覽圖：X 軸隨合圖 display zoom/pan 同步
OnLiveCurveData → return（StitchMode == Global 時跳過 UI chart 更新）
監控切向曲線圖：不更新（單台資料無意義）
OnLiveRowCurveData / UpdateLiveOverviewChart（不受 StitchMode 影響）
監控法向曲線圖：正常更新
監控全覽圖：正常更新（7 台合併曲線）
SwitchMainDisplay：IsGlobalMergeActive → return（僅切換高亮縮圖）
選中縮圖：PapayaWhip 高亮（主畫面保持合圖不切換）
DisableGlobalMerge
各相機 _mergedTargetBuffer = M_NULL（停止 callback 中的合併複製）
各相機 _mergedSrcClipLeft = 0, _mergedSrcClipWidth = 0
MdispHookFunction(M_MOUSE_MOVE + M_UNHOOK)（解除滑鼠 hook）
MdispSelectWindow(M_NULL) → MdispFree(_mergedDisplay)
MbufFree(_mergedBuffer)
SwitchMainDisplay(_selectedMainCameraId)（恢復選中相機的 secondary display）
監控主畫面：恢復為單台 MIL 即時影像
