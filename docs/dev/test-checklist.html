即時監控 Live tab

E2E-L01 啟動程式 → 自動分配相機 → 相機數狀態正確 smokehw
前置：7 台相機接好、CLProtocol 設定正確、無 grab 中

步驟

  1. 啟動 AniloxRoll.Monitor.exe
  2. 觀察右下角 lblCamCount 標籤
預期：相機: 7/7（未 Grab 但纜線接上即可偵測連線）
→ ui-flow: 即時監控 §程式啟動 — 自動分配相機
E2E-L02 按【開始抓取】→ 光源亮 → 等 300ms warmup → 第一幀畫面顯示 smokehw
前置：相機已 AutoAllocate、光源 COM 連線正常、lblLightConn 顯示已連線

步驟

  1. 按【開始抓取】
  2. 觀察光源 LED（物理光源）
  3. 觀察【監控主畫面】是否出現影像
預期：光源先亮 → 約 300ms 後相機開始 grab → 主畫面出現連續更新的影像；【開始抓取】按鈕變【停止抓取】
→ ui-flow: 即時監控 §開始抓取
E2E-L03 抓取中改 PG 曝光 → 監控主畫面亮度變化 + CSV 插 #CFG regression
前置：Live grab 進行中、PG 上「曝光」可見

步驟

  1. 拖曳【曝光滑桿1】從現值改到 +50%
  2. 放開滑桿等 1 秒（拖曳放開立刻寫硬體）
  3. 觀察【監控主畫面】亮度
  4. 關掉 grab，打開當天 CSV（D:\Anilox\Captures\YYYY\MM\YYYY-MM-DD.csv）
預期：畫面立刻變亮 + CSV 內最新一行 #CFG 內曝光值對應新設定
→ ui-flow: 設定面板 §相機參數滑桿
E2E-L04 點【監控切向曲線圖】（Vertical 模式）→ 監控強化 toggle + PG TF 即時翻轉 regression
前置：合圖方式 = 垂直、監控強化 = 否、Live grab 中

步驟

  1. 點【監控切向曲線圖】一次
  2. 觀察【監控主畫面】是否切到處理圖（亮 mura 強化）
  3. 觀察 PG 上「監控強化」是否變 是
  4. 觀察【監控切向曲線圖】是否上橘色外框
  5. 再點一次 → 應該回到原圖、PG TF 變 否、橘框消失
預期：每點一次 toggle，三項視覺（主畫面 / PG TF / 橘框）同步、不閃、PG scroll 位置保持
→ ui-flow: 即時監控 §監控曲線圖點擊
E2E-L05 點【監控全覽圖】（Vertical + 強化中）→ 切 Global + 關 enhance（一次到位） regression
前置：合圖方式 = 垂直、監控強化 = 是（橘框）、Live grab 中

步驟

  1. 點【監控全覽圖】一次
  2. 觀察主畫面切換過程（有無「先顯示舊強化版 → 再切原圖」中間幀）
  3. 觀察 PG 上「合圖方式」、「監控強化」
預期：合圖方式 → 全域；監控強化 → 否（兩個 PG cell 都翻）；主畫面一次到位 commit-on-end，無中間幀閃爍
→ ui-flow: 即時監控 §監控曲線圖點擊
E2E-L06 IO 收 PLC START → 自動 PlcStartGrab → 同 E2E-L02 流程 hw
前置：PLC 連線、lblPlcConn 已連線、未在 grab 中、IO 未暫停

步驟

  1. 在 PLC 端觸發 DI START（rising edge）
  2. 觀察 AniloxRoll.Monitor 是否自動開始 grab（同 E2E-L02 視覺）
  3. 停止 DI START → 觀察是否自動停止 grab
預期：DI START rising → 光源亮 + 相機 grab；DI START falling → 光源關 + grab 停
→ ui-flow: 即時監控 §IO 觸發抓取

歷史查詢 Review tab

E2E-R01 按【讀取資料】→ 載入最新 grab + 合圖方式 reset Global + PG 同步 smoke
前置：有歷史資料的 Anilox 資料夾、當前合圖方式 = 垂直

步驟

  1. 切到 Review tab
  2. 按【讀取資料】→ 選資料夾
  3. 觀察【回顧主畫面】、【回顧縮圖1~7】、PG「合圖方式」、PG「回顧強化」
預期：主畫面顯示最新一筆 grab 的全域合圖、縮圖 7 張、PG 合圖方式 = 全域（reset）、回顧強化 = 否（reset）
→ ui-flow: 歷史查詢 §讀取資料
E2E-R02 點【回顧切向曲線圖】（強化中 + Global）→ 切 Vertical + 關 enhance（commit-on-end） regression
前置：已讀取資料、合圖方式 = 全域、回顧強化 = 是（橘框）

步驟

  1. 點【回顧切向曲線圖】
  2. 觀察【回顧主畫面】切換過程（不該看到舊強化版緩存中間幀）
  3. 觀察 PG「合圖方式」「回顧強化」
預期：主畫面一次到位顯示新 Vertical 原圖；PG 合圖方式 = 垂直、回顧強化 = 否；canvasMain.Visible=false 包 transition 期間無閃
→ ui-flow: 歷史查詢 §回顧曲線圖點擊
E2E-R03 上一/下一序號 → 主畫面 + chartMuraProfile 同步切換
前置：Review tab 已載資料、單片模式

步驟

  1. 按【上一序號 <】或【下一序號 >
  2. 觀察 cbReviewGrabId / cbDataGrabId 是否同步
  3. 觀察【回顧主畫面】、【chartMuraProfile】是否載入新 grab
預期：所有序號 cb 同步、主畫面 + 切向 + 法向 + chartOverview + chartMuraProfile 全切換到新 grab
→ ui-flow: 歷史查詢 §單片序號導航
E2E-R04 拖曳主畫面 → chartOverview X 軸跟動 + 縮圖橘框切到對應 CAM
前置：Review tab Global mode、已載資料

步驟

  1. 滑鼠拖曳【回顧主畫面】左右移動
  2. 觀察【回顧全覽圖】X 軸範圍是否跟著移動
  3. 觀察【回顧縮圖1~7】橘框是否切到中心點落在的 CAM
預期：三者連動順暢、無遲滯
→ ui-flow: 歷史查詢 §拖曳回顧主畫面

檢測報表 Data tab

E2E-D01 按【讀取資料】→ 同步 Review tab + 統計顯示 smoke
前置：Anilox 資料夾有資料、目前 Review tab 為空

步驟

  1. 切到 Data tab
  2. 按【讀取資料】→ 選資料夾
  3. 觀察【明細列表】、【良率卡片】、【chartYearly/Monthly/Daily】
  4. 切到 Review tab → 觀察主畫面是否已載入
預期：Data tab 統計填好、Review tab 主畫面顯示最新 grab、合圖方式 = 全域、回顧強化 = 否
→ ui-flow: 檢測報表 §讀取資料
E2E-D02 點 listViewGrabDetail row → 統計 + chartMuraProfile 對齊單片，範圍 cb 不變 regression
前置：Data tab 載資料、目前在範圍模式或時序模式（cbGrabIdStart/End 已設定範圍）

步驟

  1. 記下當前 cbGrabIdStart、cbGrabIdEnd、cbStartDate/Time、cbEndDate/Time 值
  2. 滑鼠按下 listView 任一 row（不放開）→ 觀察該 row 應該反白
  3. 放開滑鼠 → 觀察良率卡片 + chartMuraProfile
  4. 檢查 cbGrabIdStart/End、cbStartDate/Time、cbEndDate/Time 6 個 cb
預期：放開才 commit、6 個 cb 值維持原狀、良率卡片改為單片 stats、chartMuraProfile 切到該 grab
→ ui-flow: 檢測報表 §明細列表點選
E2E-D03 二次點同 row → 切回範圍模式 + 範圍 stats regression
前置：E2E-D02 已執行完，當前是單片模式且 listView 有反白 row

步驟

  1. 再點同一 row 一次
  2. 觀察 listView 反白是否消失
  3. 觀察 active GroupBox（綠色高亮）切到哪
  4. 觀察良率卡片是否重新計算（範圍 stats）
預期：反白消失、GrpDataGrabIdRange 變綠（範圍模式 active）、卡片顯示 cbGrabIdStart/End 範圍 stats
→ ui-flow: 檢測報表 §明細列表點選

設定面板 + Bridge

E2E-S01 PG 改任何值 → save disk + 副作用即時生效（不閃） smoke

步驟

  1. PG 改「垂直平均閾值」從 0.2 → 0.25
  2. 觀察【監控切向曲線圖】閾值線位置
  3. 查看 bin\x64\Release\Config\inspection-settings.json 是否寫入新值
  4. 觀察 PG 改值瞬間，整個 PG 列表有無閃爍
預期：閾值線立刻移動 + disk 寫入 + PG 列表不閃（只該 cell 自我更新）
→ ui-flow: 設定面板 §檢測設定變更
E2E-S02 LightComPort 改成不存在 → 重啟 → AutoDetect 找到實際 port → PG 更新 + disk 寫回 hwregression
前置：光源實際接在某 COM（記為 COM17）

步驟

  1. 關閉 exe
  2. 編輯 bin\x64\Release\Config\inspection-settings.json，LightComPort 改成 COM99
  3. 啟動 exe → 觀察 lblLightConn 標籤
  4. 查看 PG「COM Port」欄位、查看 json 是否被寫回 COM17
預期：啟動時掃描成功 → lblLightConn 已連線 → PG COM Port = COM17 → json 寫回 COM17
→ ui-flow: 設定面板 §光源 AutoDetect
E2E-S03 改 AppRole = Storage → MessageBox + 重開後 Live tab 隱藏

步驟

  1. PG 改「機台角色」從 Inspection → Storage
  2. 觀察 MessageBox
  3. 關閉 exe 再啟動
  4. 觀察 Tab 是否只剩 Review + Data + 設定面板（Live tab 隱藏）
  5. 觀察 IO/光源/相機相關 label 是否隱藏
預期：MessageBox 提示「重開生效」、重啟後進入 Storage 模式（無 Live、無硬體 service）
→ ui-flow: 設定面板 §機台角色
