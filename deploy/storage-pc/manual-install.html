PICoater 儲存電腦安裝

第一次安裝做「程式安裝 + Windows 設定」；日後換版本只做「更新程式」。所有現場參數以 deploy\storage-pc\storage-config.json 為準。

一般安裝

  1. 解壓縮整個 Release，進入解壓後的 PICoater-Storage-版本 資料夾，不能只取出 BAT。
  2. 用記事本確認 deploy\storage-pc\storage-config.json；StorageMinFreeGB 預設為 100。正式循環清理需設為小於 AniloxRoot 所在磁碟總容量；若設定錯誤，程式只警告、不刪檔。
  3. 雙擊版本資料夾根目錄唯一的 setup.bat。
  4. 它會自動判斷：沒有既有主程式就完整安裝；已有主程式就只更新程式。更新時影像、CSV 與既有 Config 不會被覆蓋。
看到綠色「完成」後，Public Desktop 應出現 PICoater AOI 程式捷徑。先不要刪除壓縮包；完成下方驗證再移除。
舊版若安裝在 D:\AniloxMonitor，BAT 會在新 C:\AniloxMonitor\Config 尚未建立時複製舊 Config，再將排程改指向 C 槽。舊 D 目錄會先保留，確認新程式與 heartbeat 正常後才可刪除。

BAT 不能執行

PowerShell 還能執行

在版本資料夾根目錄空白處按 Shift + 滑鼠右鍵，開啟 PowerShell，執行：

powershell -NoProfile -ExecutionPolicy Bypass -File ".\deploy\storage-pc\setup.ps1"

需要人工強制指定時，在尾端加 -Mode Install 或 -Mode Update。

BAT 與 PowerShell 都不能執行

依序手動完成以下項目。欄位值一律查看 storage-config.json，不要從舊機器憑記憶抄寫。

1. 安裝程式檔案

  1. 建立設定檔 AppDir 指定的資料夾。
  2. 把壓縮包 app 內所有檔案複製進去。
  3. 檢查複製後的 EXE/DLL 「屬性」；如果有「解除鎖定」請勾選。BAT 安裝會自動處理這一步。
  4. 更新舊版本時保留目的地的 Config 資料夾。

2. 固定網路 IP

  1. 開啟「控制台 → 網路和共用中心 → 變更介面卡設定」。
  2. 選擇 NicName 指定的網卡，開啟 IPv4 內容。
  3. IP 填 IpAddress，遮罩長度 24 對應 255.255.255.0；Gateway 空白時不要填閘道。
  4. 把該網路設定為「私人網路」。

3. 建立資料夾與 SMB 共用

  1. 建立 AniloxRoot，並在其中建立 Subdirs 所列資料夾。
  2. 根資料夾內容 →「共用 → 進階共用」，共用名稱填 ShareName。
  3. 共用權限給 AllowedUser 完全控制；安全性頁籤給相同對象「修改」。
  4. Windows 防火牆允許「檔案及印表機共用」。

4. 允許 Guest 存取

  1. 「電腦管理 → 本機使用者和群組 → 使用者」啟用 Guest。
  2. 在共用權限與資料夾安全性中加入 Guest，分別給完全控制與修改。
  3. 開啟 secpol.msc：「從網路存取這台電腦」加入 Guest；「拒絕從網路存取這台電腦」移除 Guest/Guests。

5. 遠端桌面

  1. 依 RdpUser/RdpPassword 建立本機帳號並加入 Administrators。
  2. 「設定 → 系統 → 遠端桌面」啟用遠端桌面，並允許防火牆規則。

6. 設定儲存模式

在 AppDir\Config 建立 app-mode.json：

{
  "Role": "Storage",
  "StorageMachineConfigFolder": "<AniloxRoot>\\Config",
  "StorageMachineDataPath": "<AniloxRoot>\\Captures"
}

儲存電腦不使用 MIL；若程式目錄存在 Matrox.MatroxImagingLibrary.dll，請移除。

7. 自動啟動與異常重啟

  1. 開啟工作排程器，建立名稱為 StorageTaskName 的工作。
  2. 觸發程序一：「任何使用者登入時」。觸發程序二：「一次」，每 1 分鐘無限重複。動作：執行 AppDir\AniloxRoll.Monitor.exe，起始位置填 AppDir。
  3. 安全性主體選 BUILTIN\Administrators 並勾選最高權限；RdpUser 只供遠端登入，不要把排程綁死在該帳號。
  4. 工作失敗時每 1 分鐘重新啟動，重複執行時忽略新執行個體。每分鐘保活觸發可處理「正常關閉」；建立後立即執行，確認程式真正出現。

8. 關閉睡眠

「控制台 → 電源選項 → 變更進階電源設定」把睡眠、休眠與硬碟關閉時間設為「永不」。螢幕關閉時間可以保留。

驗證

一鍵測試自動重啟

  1. 在解壓縮後的 Release 根目錄，對 test_storage_restart.bat 按右鍵，選「以系統管理員身分執行」。
  2. 直接按 Enter 使用預設 3 次。工具會故意關閉儲存程式，等待工作排程以新 PID 自動重開；不會手動替排程啟動程式。
  3. 每次都必須在 90 秒內看到新 PID 與新 heartbeat。完成後程式會保持運行。
  4. 測試報告位於 D:\Anilox\Logs\DvtReports；任一輪失敗都保留報告供追查。
檢查正確結果
ipconfig指定網卡具有 IpAddress
檢測電腦開啟 \\<IpAddress>\<ShareName>不要求密碼，能建立並刪除測試檔
Public DesktopPICoater AOI 捷徑指向 AppDir\AniloxRoll.Monitor.exe
工作排程器StorageTaskName 存在且有登入＋每分鐘兩種觸發；關閉程式後最晚一分鐘內重開
檢測電腦狀態列儲存電腦共用與儲存程式心跳皆為正常
若 Guest SMB 被公司資安政策禁止，不要繞過公司政策；改由管理員建立專用帳號並同步調整兩台電腦。
