PICoater 檢測電腦安裝

第一次安裝做程式與 Windows 設定；以後只更新程式。所有現場參數以 deploy\inspection-pc\inspection-config.json 為準。

一般安裝

  1. 解壓縮整個 Release，進入解壓後的 PICoater-Inspection-版本 資料夾。
  2. 確認 inspection-config.json。
  3. 第一次安裝與日後更新都雙擊唯一的 setup.bat。
setup.bat 會自動判斷完整安裝或安全更新；更新時保留 Config，不會重新設定網卡。

BAT 不能執行

powershell -NoProfile -ExecutionPolicy Bypass -File ".\deploy\inspection-pc\setup.ps1"

需要人工強制指定時，在尾端加 -Mode Install 或 -Mode Update。

BAT 與 PowerShell 都不能執行

  1. 程式：把壓縮包 app 複製到 AppDir；更新時保留目的地 Config。
  2. IO IP：在 IoNicName 指定網卡的 IPv4 進階設定加入 IoIp/IoPrefixLength。
  3. 儲存網段：在具有 PlcSubnetPrefix IP 的同一網卡，再加入 StorageIp/StoragePrefixLength，不要刪除原有 IP。
  4. Guest SMB：在登錄編輯器把下列兩處的 AllowInsecureGuestAuth DWORD 設為 1： 
    HKLM\SYSTEM\CurrentControlSet\Services\LanmanWorkstation\Parameters
HKLM\SOFTWARE\Policies\Microsoft\Windows\LanmanWorkstation
  5. 儲存資料捷徑：在 Public Desktop 建立指向 \\VerifyPingTarget\StorageShareName 的捷徑。
  6. 檢測模式：在 AppDir\Config\app-mode.json 寫入： 
    {
  "Role": "Inspection",
  "StorageMachineConfigFolder": "<StorageMachineConfigFolder>",
  "StorageMachineDataPath": ""
}
  7. 電源：把睡眠、休眠與硬碟關閉時間設為「永不」。

驗證

檢查正確結果
ping <IoVerifyPingTarget>IO 有供電接線時可達
ping <VerifyPingTarget>儲存電腦可達
檔案總管開啟 \\<VerifyPingTarget>\<StorageShareName>不要求密碼，能建立並刪除測試檔
啟動 AniloxRoll.Monitor顯示監控模式，儲存電腦狀態可恢復為綠色
